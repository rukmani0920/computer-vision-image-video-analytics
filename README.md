# 🖥️ Computer Vision | Image & Video Analytics
An interactive Computer Vision application developed using **Python, OpenCV, and Streamlit** for exploring fundamental Image & Video Analytics techniques.

## 🚀 Live Demo
https://computer-vision-image-video-analytics-wry7yve2plmzgi28hdhwcb.streamlit.app/

## ✨ Features
- 👤 **Face Detection** – Viola–Jones based face detection
- 🔍 **Face Recognition** – Fast image-based face verification
- 🖼️ **Template Matching** – Locate a template within an image
- 📊 Interactive analysis and visual results
- 📚 Theory and technical explanation for each operation

## 🛠️ Technologies
- Python
- OpenCV
- NumPy
- Streamlit

## 📌 Purpose
This project demonstrates practical **Image & Video Analytics concepts** through an interactive and easy-to-use web application.
